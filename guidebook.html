Self Study Guidebook

웹사이트를 직접 공부하는 Codex 자습 가이드북

코드를 다 몰라도 괜찮습니다. 이 가이드북은 웹사이트 폴더를 열고, Codex에게 설명을 듣고, 작은 수정을 맡기고, 검증과 배포까지 확인하는 순서로 구성했습니다.

학습 목표

  • 웹사이트 파일 구조를 읽는 법 익히기
  • Codex에게 안전하게 수정 요청하기
  • 빌드, 링크, 화면 확인까지 검증하기
  • GitHub와 Vercel 흐름 이해하기
1. 준비하기 2. 구조 읽기 3. 수정 요청 4. 검증하기 5. 배포 이해 실습 미션 요청문 모음

Chapter 1

준비하기: Codex가 볼 수 있는 작업 공간 만들기

Codex는 열린 작업 폴더 안의 파일을 읽고 수정합니다. 처음에는 중요한 회사 코드보다 연습용 웹사이트나 복사본으로 시작하세요. 실수해도 되돌릴 수 있는 환경이 초보자에게 가장 좋은 교실입니다.

Chapter 2

구조 읽기: 파일 이름부터 이해하기

웹사이트는 보통 HTML이 구조, CSS가 디자인, JavaScript가 동작을 담당합니다. Next.js 같은 프레임워크라면 파일 위치가 조금 다르지만, 먼저 Codex에게 구조 설명을 시키면 됩니다.

처음 물어볼 요청문

이 웹사이트 폴더를 읽고 초보자도 이해할 수 있게 파일 역할을 설명해줘. 아직 코드는 수정하지 말고, 어떤 파일을 먼저 봐야 하는지만 알려줘.

Chapter 3

수정 요청: 작고 구체적으로 맡기기

좋은 요청은 목표, 범위, 확인 기준이 들어 있습니다. “예쁘게 해줘”보다 “모바일에서 버튼이 한 줄로 잘 보이게 정리하고, 수정 파일을 알려줘”가 훨씬 안전합니다.

목표

무엇을 바꾸고 싶은지 한 문장으로 적습니다.

범위

수정해도 되는 파일이나 섹션을 지정합니다.

검증

빌드, 링크, 모바일 화면처럼 확인할 기준을 둡니다.

Chapter 4

검증하기: 바뀐 결과를 믿기 전에 확인하기

Codex가 작업을 끝냈다고 해도 바로 끝난 것은 아닙니다. 변경 파일, 실행 결과, 화면 확인을 함께 봐야 합니다. 초보자는 “검증까지 해줘”를 요청문 끝에 붙이는 습관을 들이면 좋습니다.

  1. 변경된 파일 목록을 확인합니다.
  2. 가능하면 빌드나 링크 체크를 실행합니다.
  3. 데스크톱과 모바일 화면을 각각 확인합니다.
  4. 이상한 점이 있으면 Codex에게 바로 수정 요청을 이어갑니다.

Chapter 5

배포 이해: 데이터베이스가 없으면 더 단순합니다

안내 페이지, 포트폴리오, 행사 신청 랜딩처럼 저장해야 할 사용자 데이터가 없다면 정적 사이트로 충분합니다. 신청은 Google Form, 문의는 이메일 링크로 처리할 수 있고, 사이트는 Vercel에 빠르게 배포할 수 있습니다.

배포 전 확인 요청문

이 웹사이트에 데이터베이스가 필요한지 확인해줘. 필요 없다면 정적 사이트 기준으로 Vercel 배포 설정과 빌드 명령을 점검해줘.

Practice

혼자 따라 하는 실습 미션

미션 1: 사이트 설명 듣기

Codex에게 현재 웹사이트의 목적, 주요 섹션, 파일 구조를 설명하게 합니다.

미션 2: 문구 하나 바꾸기

히어로 제목이나 버튼 문구를 바꾸고, 어느 파일이 수정됐는지 확인합니다.

미션 3: 새 섹션 추가하기

자주 묻는 질문, 준비물, 강사 소개 같은 작은 섹션을 하나 추가합니다.

미션 4: 모바일 확인하기

모바일에서 글자나 버튼이 겹치지 않는지 확인하고 필요한 수정을 맡깁니다.

미션 5: GitHub와 배포

변경 사항을 커밋하고 GitHub에 올린 뒤 Vercel 배포 결과를 확인합니다.

Prompt Library

복사해서 쓰는 요청문 모음

이 프로젝트에서 초보자가 먼저 이해해야 할 파일 5개를 골라 설명해줘. 아직 수정하지 마.

내가 요청한 변경을 적용하기 전에 어떤 파일을 바꿀지 먼저 알려줘.

이 섹션을 더 읽기 쉽게 다듬어줘. 모바일에서 줄바꿈이 자연스럽게 보이도록 확인해줘.

수정 후 실행 가능한 검증 명령이 있으면 실행하고, 결과를 짧게 요약해줘.

GitHub에 올리기 전에 변경 파일과 커밋 메시지 후보를 알려줘.

Vercel에 배포 가능한 정적 사이트인지 확인하고, 배포 후 공개 URL 접속 상태까지 확인해줘.
