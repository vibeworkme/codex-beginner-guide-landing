자습용 가이드북 열기
1

작업 폴더 열기

Codex가 볼 프로젝트 범위를 정하고, 현재 파일 구조와 기술 스택을 먼저 설명하게 합니다.

2

작은 변경 요청

문구 수정, 버튼 추가, 모바일 정리처럼 되돌리기 쉬운 작업부터 맡겨 봅니다.

3

검증까지 맡기기

빌드, 링크 확인, 화면 확인처럼 결과를 눈으로 확인하는 기준을 함께 세웁니다.

4

GitHub에 올리기

변경 파일을 확인하고 커밋, 푸시, PR 또는 저장소 업로드 흐름을 배웁니다.

5

Vercel 배포

데이터베이스가 없는 정적 사이트를 빠르게 배포하고 공개 URL을 확인합니다.

    안전하게 쓰는 법

    Git, 승인 모드, 민감정보, 되돌리기, 테스트 확인 기준을 정리합니다.

    Q&A와 다음 액션

바로 쓰는 문장

초보자가 복사해서 쓰기 좋은 Codex 요청문

프로젝트 파악

이 프로젝트 구조를 먼저 읽고, 어떤 기술로 만들어졌는지 초보자도 이해할 수 있게 설명해줘. 아직 코드는 수정하지 마.

작은 수정

이 페이지의 문구와 버튼 배치를 더 자연스럽게 다듬어줘. 수정한 파일과 이유를 마지막에 짧게 알려줘.

오류 해결

에러 로그를 보고 원인을 찾아줘. 가능성이 높은 순서대로 설명하고, 가장 작은 수정부터 적용해줘.

배포 준비

데이터베이스가 필요한지 확인하고, 필요 없다면 Vercel에 배포할 수 있게 빌드와 설정을 점검해줘.
